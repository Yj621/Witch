## 게임 설명


### 🎃 **'HalloWitch'**

**할로윈의 밤**, 마녀가 되어 마을을 지켜내는 **뱀서류 로그라이크 게임**!

몰려오는 적들을 물리치며 진행도를 채우고 클리어를 목표로 하세요!

- **👻 몰려오는 적들을 잡아 진행도를 채우자**
    
    할로윈 테마의 적들이 끊임없이 몰려옵니다: **호박, 유령, 박쥐, 거미** 등!
    
    **적을 처치할수록 레벨 업**하며, 더욱 강력하고 다양한 적들이 등장합니다.
    
    적을 처치하며 **진행도를 100%**까지 채우면 **게임 클리어**!
    
    몰려오는 적들을 효율적으로 처리하여 **긴장감 넘치는 전투**를 즐길 수 있습니다.
    

- **🛠️ 다양한 스킬 트리**
    
    **수동 스킬과 자동 스킬**로 구분된 독창적인 스킬 시스템.
    
    다양한 스킬 중 **3가지를 선택**하여 나만의 플레이 스타일을 구축하세요.
    
    **적재적소에 스킬을 사용**하여 몰려오는 적들을 빠르게 처리하고 진행도를 올리세요.
    

- **✨ 다른 로그라이크와의 차별점**
    
    **자동 스킬**만이 아닌 **수동 조작 스킬**을 포함하여 **더 깊은 전략성**을 제공합니다.
    
    **시간제한이 아닌 진행도 시스템**으로, 적을 처치한 수가 게임 클리어 여부로 이어집니다.
    
    플레이어의 스킬 선택과 적 처치가 **게임의 흐름을 좌우**하며, 높은 몰입감을 제공합니다.
    

**'HalloWitch'에서 마녀가 되어 적을 물리치고, 할로윈 밤을 평화롭게 만드세요!**

스릴 넘치는 로그라이크 전투와 다양한 스킬 조합의 재미를 지금 느껴보세요! 🎃✨
